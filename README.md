# Touhou Crawl Russian localization
Unfinished translation of dungeon-crawl and touhou fan game (around 25-30% done), at least UI is somewhat translated and names of TOUHOU CHARACTERS done.
I have punctuation and spelling errors in translation

## Installation
1) Download as zip or whatever
2) Contents of "loc_files" are going into "Touhou Crawl > data > localisation > rus (create new folder basically)
3) D2Coding2_m.spritefont goes to "data > font"
4) language.txt goes to "data > localization" with overwriting OR add line "RUS,Russian,D2Coding2" in language.txt
5) In game, change language to "Russian" and you're free to go 👍
